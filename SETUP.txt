🤖 ТЕЛЕГРАМ БОТ ДЛЯ УПРАВЛЕНИЯ ЧАТАМИ И РАССЫЛКИ
================================================

📋 УСТАНОВКА И ЗАПУСК:

1. Установите зависимости:
   pip install -r requirements.txt

2. Создайте бота в Telegram:
   - Напишите @BotFather в Telegram
   - Отправьте команду /newbot
   - Следуйте инструкциям и получите токен

3. Настройте токен:
   - Скопируйте файл .env.example в .env
   - Замените your_bot_token_here на ваш токен

4. Запустите бота:
   python run.py
   
   ИЛИ напрямую:
   export BOT_TOKEN=ваш_токен && python telegram_bot.py

🔧 ФУНКЦИОНАЛ БОТА:

✅ Добавление нескольких чатов к одному пользователю
✅ Массовая рассылка сообщений во все подключенные чаты
✅ Удаление чатов из списка рассылки
✅ Просмотр списка подключенных чатов
✅ Статистика отправки сообщений
✅ История сообщений в базе данных
✅ Удобный интерфейс с кнопками

📱 КАК ПОЛЬЗОВАТЬСЯ:

1. Запустите бота командой /start
2. Добавьте бота в нужные чаты как администратора
3. Используйте "➕ Добавить чат" для подключения чатов
4. Отправляйте сообщения через "📝 Отправить сообщение"

⚠️ ВАЖНЫЕ ТРЕБОВАНИЯ:

• Бот должен быть администратором в чатах для отправки сообщений
• Для групп и каналов используйте отрицательные ID
• ID чата можно получить через @userinfobot

📁 ФАЙЛЫ ПРОЕКТА:

telegram_bot.py - основной код бота
run.py - скрипт запуска с проверками
requirements.txt - зависимости Python
.env.example - пример файла конфигурации
telegram_bot.db - база данных (создается автоматически)
bot.log - лог файл (создается автоматически)

🛠️ ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ:

- Использует pyTelegramBotAPI для работы с Telegram API
- SQLite для хранения данных пользователей и чатов
- Логирование всех операций в файл и консоль
- Обработка ошибок при отправке сообщений
- Состояния пользователей для многошагового взаимодействия
