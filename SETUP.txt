📋 УСТАНОВКА И ЗАПУСК:

1. Установите зависимости:
   pip install -r requirements.txt

2. Создайте бота в Telegram:
   - Напишите @BotFather в Telegram
   - Отправьте команду /newbot
   - Следуйте инструкциям и получите токен

3. Настройте токен:
   - Скопируйте файл .env.example в .env
   - Замените your_bot_token_here на ваш токен

4. Запустите бота:
   python run.py
   
   ИЛИ напрямую:
   export BOT_TOKEN=ваш_токен && python telegram_bot.py

📱 ПОДРОБНОЕ РУКОВОДСТВО:

🚀 НАЧАЛО РАБОТЫ:
1. Запустите бота командой /start
2. Изучите главное меню с кнопками

➕ ДОБАВЛЕНИЕ ЧАТОВ:
1. Нажмите "➕ Добавить чат"
2. Добавьте бота в нужный чат/канал как администратора
3. Получите ID чата через @userinfobot или @RawDataBot
4. Отправьте ID боту - он автоматически проверит права

📝 ОТПРАВКА СООБЩЕНИЙ:
1. Нажмите "📝 Отправить сообщение"
2. Отправьте текст, изображение, документ или другой медиа файл
3. Проверьте превью и подтвердите отправку
4. Получите подробный отчет о доставке

🔍 УПРАВЛЕНИЕ ЧАТАМИ:
• "📋 Мои чаты" - просмотр всех подключенных чатов
• "🔍 Проверить чаты" - проверка статуса бота во всех чатах
• "❌ Удалить чат" - удаление чата из списка
• "📊 Статистика" - подробная аналитика использования

⚙️ ДОПОЛНИТЕЛЬНЫЕ ФУНКЦИИ:
• Автоматическое определение типа чата

⚠️ ВАЖНЫЕ ТРЕБОВАНИЯ:

• Бот должен быть администратором в чатах для отправки сообщений
• Для групп и каналов используйте отрицательные ID
• ID чата можно получить через @userinfobot
